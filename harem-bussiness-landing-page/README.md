# Harem - Salon Management SaaS Landing Page

A modern, high-conversion landing page for **Harem**, a comprehensive multi-tenant SaaS platform designed for salon owners to manage their business, team, and clients effortlessly.

## Overview

This project serves as the B2B marketing website for the Harem platform. It features a polished, responsive design tailored to attract salon owners, showcase the platform's features, display pricing plans, and onboard new users through a multi-step signup process.

## Features

- **Dynamic Landing Page**: Engaging Hero section, detailed feature showcases, and a testimonial slider.
- **Pricing Plans**: Clear and responsive pricing tiers designed to scale from single-use to unlimited usage for large salons.
- **Multi-Step Onboarding**: A smooth, interactive multi-step signup flow to get salon owners set up quickly.
- **Authentication**: Custom login and signup interfaces.
- **Corporate Pages**: Includes Contact Us, Privacy Policy, and Terms of Service.
- **Responsive Design**: Flawless experience across desktop, tablet, and mobile devices.

## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [AOS](https://michalsnik.github.io/aos/) for smooth scroll animations.
- **Sliders**: [Swiper](https://swiperjs.com/) for interactive carousels.
- **Icons**: [Lucide React](https://lucide-dev.github.io/lucide-react/)
- **Language**: TypeScript
